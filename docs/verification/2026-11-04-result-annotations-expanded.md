# Closed result annotations: expanded author verification

4 November 2026. This extends source `4e15873`, with an intermediate recovery
checkpoint at `da64389`. The planned author matrix is complete. Independent and
full acceptance remain pending; this does not complete P1, C02, kinds, skolems
or annotated interfaces.

## Graph-wide input bound

The first spine reset its module allowance for each parsed file. That did not
establish a whole-program cumulative bound before the rewriter cloned functions.
This checkpoint uses one borrowed budget across all parsed modules. A second
borrowed pass, also shared across the complete graph, counts the exact resolved
name lengths before any annotation tree is cloned or rewritten. It computes
`M$<symbol index>$<name>` byte lengths without allocating those names. Raw C
pointee subtrees retain their spelling and are fully counted without Rill lookup.

Both passes independently enforce depth 128, 16 MiB logical weight per tree,
64 MiB cumulatively and 4,000,000 node visits. A node costs 64 logical units plus
name bytes. These are annotation-policy units, not whole-compiler memory limits.
The actual public AST guard remains first in checking, before recursive consumers.
Existing parameter/declaration policies are unchanged. Width/work tests prove
charging before the next child is visited; injected graph budgets test exact
combined limits and resolved-name growth. Other tests cover UTF-8 names, raw
pointees, exact depth 128 versus 129 and the actual 16 MiB per-tree boundary.

historical evidence. This is a bounded compatibility corpus, not a universal
inference-equivalence proof or a claim that all expression types were compared.

## Executed coverage

A fresh broad GCC command passed all **657 selected tests** in one invocation:
487 library tests and 170 integration tests. The Clang execution target then
passed all six tests. Default strict Clippy and formatting pass, and the CLI
example prints exactly `42` followed by a newline. These final checks were rerun
after the four nonsemantic lint cleanups described below.

```sh
CC=gcc cargo test --locked --lib --test result_annotations \
  --test result_annotation_origins --test result_annotation_execution \
  --test ast_source_map --test type_solver --test value_restriction \
  --test typed_discarded_results --test typed_discarded_records \
  --test typed_local_values --test typed_node_origins \
  --test typed_source_origins --test typed_foreign \
  --test returned_owner --test owner_adt --no-fail-fast -- \
  --test-threads=1 --nocapture
CC=clang cargo test --locked --test result_annotation_execution -- \
  --test-threads=1 --nocapture
cargo clippy --locked --all-targets -- -D warnings
cargo fmt --all -- --check
cargo run --locked -- run examples/result-annotations/main.rill
```

The new execution harness completed **280 actual C11 executions**, 140 with GCC
and 140 with Clang, evenly split O0/O2 with `-pedantic-errors`. Each compiler ran
64 pure, 6 contextual/interrupted, 18 return/discard/depth-event, 36 native,
12 owner and 4 imported-module executions. These are new annotation cases,
separate from unchanged selected regressions. Earlier partial/rerun executions
are not added to that count. No combined count is claimed for C runs performed
by the older selected test harnesses.

Pure cases cover observed/mutable empty options, nested records/options, static
UTF-8 strings, unit/bool, vectors and vector enums, generic parameters with a
closed result, a constrained identity, lowercase nominal names, field loans,
written field order, a three-member SCC and dead traps. Direct typed lowering,
verification and emission are required; default emitted C must be byte-identical.
Reference/default/direct typed evaluation agree, and explicit reference C runs
where supported. Contextual cases preserve their existing reference-emitter
classification separately rather than silently substituting another backend.

Event checks retain normal discarded-call effects, E1/E2/L2/L1 return frames,
actual main-inclusive E1 through E33 recursion-depth trapping, and an earlier
callee trap. Native wrappers preserve exact scalar/raw-pointer/const-pointer/unit
ABI and call events, while reached native evaluation remains rejected. Owner
cases preserve returned-owner transfers, caller/callee cleanup, inactive closed
owner enums, bytes and abort-without-cleanup behavior. No owner records or new
owner/native combinations are added.

Seven private Copy-origin corruptions reject wrong result roots, including an
identical parameter annotation, a nested child and another function result.
Six mandatory control-proof corruptions reject changed phantom arguments,
witness signatures, source identity, demand and substitutions through ordinary
verification/evaluation/emission without optional maps. Namespace/privacy tests
cover same-spelled nominal types, separate type/value namespaces, private imported
results and unused nested/phantom leaks. AST coverage has an independent result
subtree count, exact UTF-8 spans and malformed-input checks. Unused definitions
remain NotInstantiated. Optional native/owner/contextual origin exclusions and
raw-C-pointee owner-classifier parity remain unchanged.

The experimental example is `examples/result-annotations/main.rill`; its CLI
execution prints `42`, matching the C-tested mutable-option case. Public
`Function.result_annotation`, `AstStep::FunctionResult`, and
`GenerationReason::AnnotatedResultType` are intentional experimental API-shape
changes, including exhaustive matches in downstream Rust callers.

## Retained failures and remaining work

All failed logs and new execution fixtures are retained. Semantic-test and
compilation failures during development were in new test/harness code: a missing
BTreeMap key type, missing PathBuf borrows, accidental `>=` tokenization in type-declaration fixtures,
an overly narrow foreign-error text assertion, unsupported unparenthesized match
arithmetic, a nonexistent selected test target, and the vector diagnostic
expectation (`E-ARITY` instead of the existing `E-TYPE` for `u8x16<i32>`). The
first broad run passed 656 of 657 tests; its one diagnostic assertion was fixed
and its entire ten-test target passed before the fresh all-green run. Fixtures
were corrected without relaxing production behavior. Final strict lint initially
flagged four redundant borrows of the budget's error callback. Removing those
extra borrows leaves the same closure and failure paths; the complete selected
suite and both C compiler matrices passed again afterward.
The first expanded run completed 88 C executions before its failures; the next
executable run completed 136 before the final module C case was added. Neither
is advertised as additional final coverage.

Independent review and fresh full default/importer/Windows aggregate gates remain
pending. Final acceptance documentation and publication remain pending. Builds
used the sole target, two jobs, zero debug information, no incremental compilation,
and the required capacity checks before Cargo builds.
The new annotation C harness additionally checks the floors before each compiler
invocation. Older unchanged harnesses keep their own existing behavior; no claim
of newly added per-invocation guards is made for them.
