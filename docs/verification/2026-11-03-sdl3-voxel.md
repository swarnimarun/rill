# SDL3 voxel core verification

This historical record is retained from archive snapshot `69277817`.
Fresh verification of the port onto `v1-ernie` is recorded in the
[integration report](2026-11-04-ernie-integration.md).

The [example](../../examples/sdl3-voxel/CPU-README.md) implements a bounded voxel
simulation and CPU distance-field lighting in Rill. This does not complete a
language phase or establish production-engine performance.

## Focused checks

On AArch64 macOS with installed SDL3 development files:

```sh
cargo test --locked --test sdl3_voxel -- --nocapture
cargo test --locked --no-fail-fast
cargo fmt --all -- --check
cargo clippy --all-targets -- -D warnings
```

All 10 voxel integration tests passed. The full default-feature repository
suite completed successfully with exit zero. Formatting and strict all-target
Clippy passed. Each of the eight pure drivers compared the checked interpreter with
emitted C at `-O0` and `-O2`. The two native tests exercised actual SDL3, not a
mock or dependency skip.

The pure drivers covered all 512 storage cells and six world boundaries,
clipped spherical destruction, bedrock preservation, extreme blast centers,
sideways support propagation, disconnected-stack gravity, material conservation,
exact signed distances including exterior air and a new cavity, an empty field,
a thin ray occluder, emitter removal and an opened roof.

The native framebuffer test ran eight frames at each optimization level under
`SDL_VIDEODRIVER=dummy`, scripted destruction of the four pillars, and stepped
gravity. Both main results were zero, both real BMP captures contained drawing,
and their bytes matched exactly. A native C adapter test pushed real SDL mouse,
keyboard and quit events, including complete down/up pairs in consecutive polls.
It did not simulate physical desktop input.

The SDL-free headless example returned `204` through both interpretation and C
at `-O2`. Independent review checked exact nearest-source distances across all
512 cells with sources in mixed octants, and confirmed the initial scene has
124 occupied cells and material sum 224 through both execution paths.

## Failure found and corrected

Initial large functions exceeded the existing C emitter's frame estimate.
Smaller scene, physics, lighting and rendering functions passed that check.
The unoptimized SDL smoke then exposed cumulative stack overflow. An
AddressSanitizer backtrace identified the lighting gather/ray call chain.
A bounded six-direction gather loop shortened the chain while preserving ray
order, weights and the direct-light snapshot. The unchanged default host stack
then passed both optimization levels. A fresh unoptimized AddressSanitizer
smoke also exited zero without sanitizer diagnostics.

No stack threshold was raised, no compiler check was disabled, and no simulation
was moved into the C adapter. See [remaining scale limits](../blockers/voxel-native-scale.md).

## Scope of the evidence

Lighting uses a signed Manhattan grid transform and six scalar one-bounce rays.
It is SDFGI-inspired, not continuous Euclidean SDFGI or GPU light transport.
Gravity is cellular and conserves material, with no rigid-body rotation or
momentum. These checks establish behavior of the bounded example on this host,
not frame-rate, hard realtime, allocation-free execution or portability claims.
