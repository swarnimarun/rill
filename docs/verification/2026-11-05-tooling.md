generation replacement, improved rejection help and Rust migration material.

## Full-run failures and repairs

The sweeps compiled their test binaries before these two test-only repairs:

- The lossless lexer position test expected the old entire message. New `?`
  help intentionally added a second line; the location/headline were unchanged.
  The repaired test checks the exact first line, exact optional help and absence
  of extra lines, and adds `&` coverage. All 11 source-format tests pass. A
  separate root rerun of the exact position test also passes.
- Configured SDL capture failed with missing `AvailabilityMacros.h` because
  `SDKROOT` was unset. The capture/import/product code was unchanged; setting
  the discovered SDK made the original case pass. The macOS fixture now saves
  explicit `-isysroot` arguments in its recipe when `SDKROOT` is absent, without
  mutating global environment or overriding an explicit SDK. All 15 native
  configuration tests pass with `SDKROOT` removed, including O0/O2 saved SDL
  capture/materialization/execution. A separate root rerun of that SDL case
  passes with the same unset environment.

The native configuration raw-filename case reports its existing runtime skip
when macOS rejects creation of a non-UTF8 directory. This is additional to the
four GPU early-return paths above. The repaired tests preserve coverage; they
do not relax compiler/native validation or turn a failure into a skip.

## Measurements and limits

The [timing record](2026-11-05-incremental-speed.md) documents five-sample
release measurements. On the string-equality build, 5,000-unused-declaration
emission went from 72.570 ms to 6.849 ms on a hit, and O3 builds from
117.776 ms to 52.562 ms. An earlier run also observed about a 2.2-times build
speedup; absolute times varied with host activity.
Changed graphs still recheck completely and pay cache publication overhead.
No executable/object reuse, per-module checked-body cache or new library-size
budget is claimed.

Native sessions replace entire checked scalar library generations between
exclusive calls. There is no owned-state migration, retained callback support,
active-frame patching or general concurrent unload. See the
[remaining contract](../blockers/hot-reload.md).

Rust migration examples/recipes are executed, while the
[ranked language increments](../proposals/next-language-increments.md) remain
discussion proposals. `break`, `continue`, early return, iterators, local type
annotations and hosted argv are not implemented by the new diagnostic hints.
