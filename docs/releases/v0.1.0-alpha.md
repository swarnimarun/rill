# Rill v0.1.0-alpha

Experimental Rust compiler targeting C11, with explicit binary32 operations,
project native/shader recipes and an SDL3 GPU renderer example written around
Rill scene, camera, mesh and transform logic.

The default archives include Slang, SDL3, a SPIR-V validator, the Slang C ABI
bridge, bundled standard modules, documentation, examples and upstream notices.
A platform C11 compiler/SDK is still required. Automatic C import also requires
libclang. See [distribution instructions](https://github.com/swarnimarun/rill/blob/v0.1.0-alpha/docs/distribution.md)
and [graphics limitations](https://github.com/swarnimarun/rill/blob/v0.1.0-alpha/docs/graphics-feature-audit.md).

`rill shader check|build|inspect` compiles external shader languages through
structured tool arguments. SPIR-V uses actual validation; emitted MSL requires
runtime Metal compilation. Project watch rebuilds native/shader candidates and
keeps the old process alive when a candidate fails. Stateful GPU pipeline hot
replacement remains future work.

This release does not establish Rust/Zig feature parity or completion of PLAN
phase gates. General foreign ownership, GPU resource proofs, float literals,
arrays/slices and a stable package ABI remain open.
