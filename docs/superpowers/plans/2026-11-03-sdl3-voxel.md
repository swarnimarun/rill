# SDL3 voxel core implementation plan

> **For agentic workers:** Use independent workers for world/physics and lighting, then review integration together. Track completion below.

**Goal:** Add a destructible voxel sandbox written in the currently accepted Rill subset, with independently testable simulation and lighting.

**Architecture:** Pure Rill modules own an 8×8×8 material volume, support connectivity, fixed-step gravity, signed grid distances and bounded indirect-light rays. A small C adapter handles SDL events and scalar drawing calls because Rill cannot read SDL event aggregates. Rill owns projection, picking, destruction, lighting and the loop.

**Tech stack:** Rill, generated C11, SDL3, Rust integration tests.

**Spec:** User request in this session; current syntax and foreign limitations in `README.md` and `docs/c-interop.md`.

## Global constraints

- Preserve the concurrent agent's changes. Add isolated files; no compiler changes.
- Use braces and semicolons. No foreign calls or owned buffers in pure core modules.
- Use bounded Copy byte storage and integer math. State capacities and approximations explicitly.
- Do not describe this as a production engine, full SDFGI, or a completed language phase.

### Task 1: World, destruction and support physics

Files: `examples/sdl3-voxel/world.rill`, `physics.rill`.

Interfaces: `Volume<a> { low: a; high: a }`; `empty()`, `get(read volume, x,y,z)`, `set(inout volume,x,y,z,material)`, `inside(x,y,z)`, `scene()`; `blast(inout cells,x,y,z,radius)` returns removed count; `step(inout cells,inout support)` returns moved count. Material 0 is air, 1 is immovable bedrock, 2/3 are diffuse solids, 4 emits light. Outside samples are air. Coordinates are 0..7.

- [x] Create storage and a small scene with a roof, pillars and an emitter.
- [x] Implement clipped spherical edits preserving bedrock.
- [x] Flood support from bedrock and the bottom plane; drop unsupported voxels one cell per tick, bottom-up, without overwriting occupied cells.
- [x] Verify isolated voxel fall, connected support, bedrock, boundaries and mass conservation through pure Rill checks and integration tests.

### Task 2: Signed distance and indirect lighting

File: `examples/sdl3-voxel/lighting.rill`.

Interfaces: `rebuild(read cells,inout sdf,inout light)`; `distance(read sdf,x,y,z)` returns signed integer grid distance; `sample(read light,x,y,z)` returns brightness 0..255. Uses Task 1 Volume storage. Distances encode 128 + signed distance; air positive, solids negative.

- [x] Reconstruct distances to the opposite occupancy class using bounded Manhattan-grid relaxation.
- [x] Trace conservative distance-guided rays to sky and emissive/diffuse surfaces; gather low-resolution indirect illumination.
- [x] Rebuild after every edit and gravity move; verify distance signs, occlusion, emitter response, and destruction invalidation.

### Task 3: SDL sandbox and regression evidence

Files: `main.rill`, `render.rill`, `native.rill`, `platform.c`, `run.sh`, `README.md` in the example; `tests/sdl3_voxel.rs`.

Interfaces: scalar platform calls for window lifecycle, event polling, input, time, color and lines; Rill handles isometric face rasterization and frontmost cell picking. A headless pure Rill executable exercises engine behavior without SDL.

- [x] Add the window, isometric world, mouse blast/build, reset and lighting/distance views.
- [x] Bound catch-up ticks, drain events, check SDL errors and clean every resource path.
- [x] Compare deterministic core results through the interpreter and C at `-O0`/`-O2`; run a real dummy-driver SDL smoke test if installed.
- [x] Document build commands, controls, ownership and performance limitations. Review only new files and run fmt, relevant tests and Clippy.

## Implementation notes

- Function parameters infer fixed byte storage through `world.empty()` because the current syntax cannot name that buffer type in an annotation. The descriptive `Volume<a>` interface above does not introduce function type-parameter syntax.
- Mouse input uses queued press edges, including clicks released before the next poll. A real SDL pushed-event regression covers consecutive clicks.
- Native uniform-value C frames required smaller functions. An AddressSanitizer-confirmed cumulative stack overflow in unoptimized lighting required shortening the gather call chain, preserving the six-ray computation.
- Eight-frame native smoke comparisons use a scripted blast through all four pillars, then gravity, with real BMP equality at `-O0` and `-O2`.
- Remaining engine scale and language boundaries are recorded in `docs/blockers/voxel-native-scale.md`; no phase gate is marked complete.
